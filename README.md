# Sarah Sweets

A custom-designed, responsive website for **Sarah Sweets**, a Dallas chocolatier specializing in personalized chocolates, event favors, gift boxes, trays, and celebratory treats.

## Website features

- Premium mobile-responsive custom design
- Sarah Sweets-inspired cream, cocoa, rose, and gold visual system
- Interactive custom-order brief builder
- One-click Instagram and phone contact
- Occasion selector for weddings, baby celebrations, graduations, Eid, Ramadan, Hajj, teacher gifts, and more
- Accessible navigation and keyboard-friendly order modal
- Scroll animations with reduced-motion support
- Custom SVG favicon
- No framework or build step required

## Run locally

Open `index.html` in a browser, or use any static web server.
